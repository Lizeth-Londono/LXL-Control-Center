# LXL Control Center

Cotizador público y panel administrativo demostrativo de LXL.

Tecnologías: HTML, CSS y JavaScript, con Bootstrap Icons y fflate local.

Para ejecutar localmente, sirve esta carpeta con un servidor estático, por ejemplo Live Server en Visual Studio Code, y abre `index.html`.

Sitio público: https://lizeth-londono.github.io/LXL-Control-Center/

El panel `/admin/` es una demostración pública, sin autenticación, persistencia ni operaciones de servidor. Sus registros son ilustrativos.

Archivos ZIP permite análisis estático local en un Worker, con límites configurables, cancelación e informe JSON. No envía archivos ni ejecuta su código. El borrador de alcance queda sin importes hasta contar con tarifas aprobadas. Límites y pruebas: [ZIP-OPERATIVO.md](ZIP-OPERATIVO.md).

v3.3 añade Informes y Cotizaciones: importación JSON local, tarifas explícitas y PDF DEMO. Sin precios oficiales precargados ni factura electrónica. Uso, pruebas y límites: [COMMERCIAL-v3.3.md](COMMERCIAL-v3.3.md).
