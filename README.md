# LXL Control Center

Cotizador público y panel administrativo demostrativo de LXL.

Tecnologías: HTML, CSS y JavaScript, con Bootstrap Icons.

Para ejecutar localmente, sirve esta carpeta con un servidor estático, por ejemplo Live Server en Visual Studio Code, y abre `index.html`.

Sitio público: https://lizeth-londono.github.io/LXL-Control-Center/

El panel `/admin/` es una demostración pública, sin autenticación, persistencia ni operaciones de servidor. Sus registros son ilustrativos.
